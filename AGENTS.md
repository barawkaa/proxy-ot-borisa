# Правила работы над Proxy от Бориса

- Приложение для личных задач Бориса: Home Assistant OS, Raspberry Pi 4 aarch64.
- Перед разработкой обсуждать изменения. Разрабатывать и выпускать только после команды Бориса. Согласованный ремонт 5.2 авторизован 07.10.2026.
- Каждое исправление доставляется полной новой версией, а не ручной заменой отдельных файлов на HA. Ветка разработки может содержать несколько исправлений до выпуска.
- Версии X.0–X.9; после десяти версий нужен полный пересмотр и переписывание следующего поколения по согласованию.
- Не удалять функции без согласования. Дополнительные функции переносить в настройки. Прокси по спискам, trusted, ручной выбор, HTTP, SOCKS5, Telegram, доступы клиентов и история сохраняются.
- Интерфейс простой и информативный; инструкции пользователю по одному шагу. Не перекладывать доступные разработчику проверки на Бориса.
- Секреты подписок и клиентов не публиковать. GitHub хранит код; личные данные — резервное копирование HA.
- Старые теги и релизы неизменяемы. Новый релиз содержит всю структуру приложения и описание отката.
- Перед выпуском проверить требования по docs/RELEASE-CHECKLIST.md. Не считать пройденные модульные тесты доказательством работы в HA.
- Сообщать фактически выполненные проверки, пропуски, ограничения и неуверенность. Не обещать отсутствие всех ошибок.
- При дефекте сначала установить причину, затем исправить и воспроизвести исходный сценарий в тесте. Проверять также связанные действия и ошибки.
- Не выпускать при провале обязательных проверок. Проверить точный коммит кандидата, после слияния — точный коммит main и создание релиза.
- Не менять сетевые настройки пользователя, способные оборвать удалённый доступ, без одновременно подготовленного отката.
- Не использовать параллельных агентов без явного запроса пользователя.
