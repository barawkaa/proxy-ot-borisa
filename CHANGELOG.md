# Changelog

## 1.21.2

- Удалены дублирующиеся top-level функции backend: теперь smoke-test падает, если в коде снова появятся перезаписывающиеся определения.
- Добавлен расширенный API-contract smoke-test: все литеральные `/api/...` вызовы интерфейса проверяются на наличие backend-роута.
- Аудит отделён от технического лога: `/data/audit.json` для событий доступа/безопасности, `/data/events.json` для технических событий.
- Раздел обслуживания теперь показывает размер отдельного audit-журнала и лимит его хранения.
- Усилен первый запуск: диагностика предупреждает о дефолтном secret, дефолтном proxy password, неполной авторизации и отсутствии пользователей.
- В `config.yaml` включён `panel_admin: true`, а HTTP proxy auth теперь включён по умолчанию.
- Добавлен runtime `production_mode`: обычный, диагностика, отладка и безопасный режим.
- Безопасный режим блокирует изменяющие API-операции, кроме смены режима, обслуживания и очистки аудита.
- Прямые перезапуски sing-box/MTProto в пользовательских API заменены фоновым применением там, где это возможно.
- Dockerfile возвращён на проверенную схему с `ghcr.io/sagernet/sing-box:latest` и `ghcr.io/dolonet/mtg-multi:latest`, чтобы Home Assistant снова собирал add-on без fragile source-build mtg-multi.

## 1.20.1
- Исправлены отсутствующие API `/api/audit` и POST `/api/routing/test`, из-за которых аудит и проверка маршрута возвращали 404.
- Пароли и MTProto secrets теперь раскрываются по клику и снова скрываются по повторному клику.
- Исправлена верстка карточек в настройках: заголовок и описание больше не слипаются.
- В обслуживании путь пользователей исправлен на реальный `/data/proxy_users.json`.
- Расширены smoke-тесты на frontend/backend API-связки.

## 1.20.0

- Крупная версия стабильности и безопасности.
- Добавлена схема миграций данных `/data/migrations.json`, чтобы старые `users.json` и runtime-настройки не ломались после обновлений.
- Добавлен безопасный apply sing-box: предварительная проверка `sing-box check`, сохранение последнего рабочего конфига и rollback при ошибке нового конфига.
- Добавлен раздел `Настройки → Аудит` для чистого журнала событий доступа, пользователей, безопасности и серверов.
- Добавлен раздел `Настройки → Обслуживание`: размер файлов данных, история, аудит, свободное место, ручная очистка по правилам хранения.
- Добавлена проверка маршрута домена/IP во вкладке `Маршрутизация`.
- Добавлена ротация доступа пользователя: смена пароля и Telegram secret одной операцией.
- Пользователи получили поля группы, срока действия, masked-поля пароля/secret в интерфейсе.
- Резервная копия теперь может создаваться с секретами или с замаскированными секретами для безопасной передачи в поддержку.
- Расширены smoke-проверки перед сборкой: Python import, основные функции, JS syntax, YAML, соответствие HTML id.
