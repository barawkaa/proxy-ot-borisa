# Proxy от Бориса

**VPN-подписка одна — доступ на разных устройствах без отдельного VPN-приложения на каждом.**

Proxy от Бориса — приложение для Home Assistant OS, которое принимает VPN-подписки и отдельные серверы и предоставляет вашей технике обычные HTTP, SOCKS5 и Telegram MTProxy. Вы добавляете подключения, а приложение проверяет серверы, выбирает подходящие и переключается при отказе.

Это полезно, когда телефон работает с VPN, а телевизор, игровая консоль или другая программа умеет только HTTP-прокси. Например, Nintendo Switch можно подключить к домашнему HTTP-прокси, а Telegram — по персональной ссылке. Устройства должны поддерживать соответствующий тип прокси: приложение не превращает любой сетевой трафик в VPN автоматически.

Проект создаётся для домашнего использования на **Home Assistant OS / Raspberry Pi 4, aarch64**. Это не VPN-провайдер: действующая подписка или собственные серверы нужны отдельно.

## Как это устроено

1. Добавьте одну или несколько подписок либо вставьте отдельные серверы.
2. Выберите «Подключить устройство» и получите адрес, данные доступа или ссылку Telegram.
3. Приложение поддерживает подключения, проверяет резерв и показывает причины переключений.

HTTP, SOCKS5, Telegram и HTTP с одобрением IP имеют **независимые выбранные серверы и резервы**. Плохая работа Telegram на одном узле не заставляет менять исправный маршрут HTTP. Измерения серверов используются совместно, чтобы не тратить ресурсы на четыре одинаковых проверки.

## Что можно подключить

| Прокси | Сценарий | Доступ |
| --- | --- | --- |
| HTTP | Браузер, приложение, техника с HTTP-прокси | Персональный логин и пароль или явно доверенный адрес |
| SOCKS5 | Приложение с поддержкой SOCKS5 TCP | Персональный логин и пароль или доверенный адрес |
| Telegram MTProxy | Telegram на телефоне или компьютере | Персональный секрет, ссылка и QR-код |
| HTTP по IP | Домашняя техника без поля пароля; приглашённые пользователи | Домашние подсети автоматически, внешние IP после одобрения |

Порты по умолчанию: **2081 / 2080 / 2083 / 2084**. Все четыре видны в общей форме и на отдельных вкладках. Порты можно менять с проверкой конфликтов. Новые внешние разрешения ограничены сроком по умолчанию; постоянный доступ включается явно. Отзыв закрывает действующие соединения.

## Что приложение делает автоматически

- Обновляет несколько подписок, сохраняет имена и разделяет источники по вкладкам. Неполное обновление не удаляет молча прежние серверы.
- Импортирует поддерживаемые подключения: VLESS, VMess, Trojan, Shadowsocks, SOCKS и HTTP, а также поддерживаемые структуры sing-box/Clash. Не все расширения провайдеров совместимы; неподдерживаемые параметры отображаются как ошибка импорта или проверки ядром.
- Измеряет задержку **HTTPS через сервер**, проверяет зарубежные и российские адреса, отдельно — выбранные сервисы. Это не ICMP ping.
- Поддерживает свежие проверки активных маршрутов и резервов; остальные проверяет по очереди. После повторных отказов увеличивает интервал проверки проблемного узла.
- Переключает отказавший маршрут, а ради небольшого колебания задержки сохраняет соединение. Улучшение подтверждается повторными измерениями.
- Для Telegram проверяет обмен MTProto через собственный MTProxy. Дополнительная проверка фрагмента контрольного файла позволяет учитывать загрузку медиа.
- Восстанавливает процессы после отказа с паузами между попытками. Отклоняет неверную конфигурацию до применения, возвращает предыдущую при неудачном запуске.
- Ограничивает историю по сроку, числу записей и размеру. Технические журналы процессов остаются в ограниченном буфере памяти.

Ручной выбор сервера доступен на главной отдельно для каждого прокси. При желании приложение может подменить ручной выбор резервом при отказе.

## Только нужные сайты через VPN

Режимы: всё через VPN, только домены/IP из списков, всё кроме исключений, прямой доступ. Есть общие правила, настройки отдельных прокси и исключения для клиентов. «Напрямую» означает выход с сервера Home Assistant без VPN, а не обход HTTP-прокси самим устройством.

Списки можно обновлять по URL. Приложение не определяет автоматически полный перечень всех заблокированных ресурсов: маршрутизация следует заданным правилам.

## Telegram-уведомления и Home Assistant

**Через интеграцию HA:** выберите одного или нескольких настроенных получателей Telegram. Можно дополнительно указать ID чатов вручную для выбранного бота HA. Копировать его токен в приложение не требуется.

**Напрямую:** введите токен бота и ID чата. Для общего бота HA приём кнопок должен оставаться выключенным. Прямые кнопки одобрения доступны только при явно выбранном отдельном боте.

По умолчанию уведомляются запросы по приглашению после реального HTTP-запроса. Повторы объединяются и ограничиваются по частоте. Это снижает шум от сканеров, но не является гарантированным распознаванием человека.

Для Lovelace поставляется локальная интеграция: состояния четырёх прокси, резерв, задержка, время смены, доступность, выключатели, списки выбора серверов и кнопка проверки. Компактная карточка использует стандартные элементы HA, **без HACS и MQTT**. Установка интеграции выполняется отдельной кнопкой в приложении; после первой установки нужен перезапуск HA и добавление интеграции. HA автоматически не перезапускается.

## Установка

1. Добавьте `https://github.com/barawkaa/proxy-ot-borisa` как репозиторий приложений в Home Assistant OS.
2. Установите «Proxy от Бориса» и запустите его.
3. Откройте интерфейс через боковую панель HA, добавьте подписку и подключите первое устройство.

Интерфейс управления работает через авторизацию Home Assistant Ingress. Приложение использует сеть хоста; внешний доступ к портам зависит от вашей сети, маршрутизатора и провайдера. Включение прокси само по себе не создаёт переадресацию портов на роутере.

## Защита и честные ограничения

- Персональные доступы, ограничения подключений, временные блокировки после ошибок входа; внешний HTTP по IP не передаёт запрос до разрешения владельца.
- HTTP по IP блокирует назначения в частных сетях, чтобы разрешение на интернет не открывало интерфейс HA или роутера.
- Когда подтверждённого VPN-маршрута нет, VPN-трафик блокируется; незаметного переключения на прямой выход нет. Явные прямые правила продолжают действовать.
- IP идентифицирует сетевой выход, а не физическое устройство. За одним адресом могут находиться несколько людей, и внешний адрес может сменить владельца.
- Один контрольный Telegram-файл не гарантирует загрузку всех видео. Без настройки файла нет ложного статуса «медиа проверены».
- Ответ сайта 403/429 может означать ограничение автоматической проверки, а не блокировку VPN.
- Защита приложения не устраняет DDoS, который перегружает интернет-канал до домашнего роутера.

## Версии, данные и проверки

Каждый выпуск — полное приложение. Старые теги и релизы сохраняются. **GitHub хранит код, штатная резервная копия HA — ваши настройки, подписки, клиенты и историю.** Для полного отката используйте резервную копию приложения перед обновлением; архив старого исходного кода сам по себе личные данные не восстанавливает.

Проверки перед релизом: Python/API, реальные sing-box и MTG, сценарии отказов, браузер на компьютере и телефоне, обновление со старым кешем, ARM64-образ и интеграция на Home Assistant 2026.9.4. Их результат относится к проверенному коммиту. Фактические блокировки провайдера, скорость конкретной подписки, уведомления вашего бота и длительная работа домашнего оборудования требуют проверки в вашей сети.
