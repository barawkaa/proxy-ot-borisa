# Proxy от Бориса 5.2

Личное приложение для **Home Assistant OS / Raspberry Pi 4 aarch64**. Подписки и отдельные VPN-серверы → HTTP, SOCKS5 TCP и Telegram MTProxy.

> Результаты автоматических проверок и ARM64-сборки доступны в [GitHub Actions](https://github.com/barawkaa/proxy-ot-borisa/actions/workflows/verify.yml). Проверка в домашней сети и на конкретной установке HA OS выполняется отдельно.

## Основные возможности

- Ручной выбор сервера на главной и автоматический выбор с защитой от постоянных переключений.
- Несколько подписок, отдельные вкладки, ручные серверы и общий список.
- Сохранение исходных названий/флагов; стабильные идентификаторы по полным настройкам подключения.
- VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC, SOCKS и HTTP outbounds. JSON sing-box, поддерживаемые Xray JSON, Clash YAML, URI и Base64. Каждый узел дополнительно проверяется выбранным ядром.
- Проверки через каждый VPN отдельно, без переключения активного соединения ради измерения. Зарубежные, российские сайты и отдельные сервисы отображаются раздельно.
- Повторная проверка отказа, проверка резервов и автоматическая замена. Серверы с ограничениями российских сайтов остаются резервными.
- Единая карточка клиента: HTTP/SOCKS5/Telegram, пароль, полный секрет, ссылка и локально сгенерированный QR.
- Три варианта VPN-маршрутизации и прямой режим; правила клиента, списки доменов/CIDR, исключения, обновляемые списки.
- HTTP/SOCKS5 trusted-доступ по CIDR с явной привязкой к клиенту, блокировки, allowlist и ограничение соединений.
- Активные подключения, история, учтённый трафик; ограничение истории по сроку и объёму.
- Проверка конфигурации до применения, восстановление процессов с паузами, Supervisor watchdog.

## Структура

`proxy-ot-borisa/boris/` — отдельные модули импорта, модели, хранилища, маршрутизации, ядра, прокси-шлюзов, проверок и API. `ui/` — интерфейс без внешних CDN. `tests/` — регрессии и сквозные тесты с реальными бинарниками.

## Обновление

1. Сделайте резервную копию **дополнения Home Assistant с его данными**.
2. После выпуска 5.2 обновите сведения о репозитории и приложение в Home Assistant.
3. Откройте приложение, проверьте отчёт переноса, обновите подписки и выполните «Проверить всё».

Файлы 4.x не перезаписываются миграцией. Новая конфигурация: `/data/config-v5.json`. Новая история: `/data/history-v5.sqlite`. Данные имеют разные форматы: откат кода сам по себе не переносит изменения 5.1 в 4.x.

## Для разработчика

```bash
pip install -r proxy-ot-borisa/requirements.txt
PYTHONPATH=proxy-ot-borisa python -m unittest discover -s proxy-ot-borisa/tests -v
```

Сквозные тесты: установите `CORE_INTEGRATION=1`, `SINGBOX_BIN` и `MTG_BIN` на обычном Linux. Workflow не пропускает эти тесты. ARM64-образ собирается отдельным заданием. Ни подписки владельца, ни настоящие секреты в CI не передаются.
