# Proxy от Бориса

Коротко: это Home Assistant add-on, который превращает ваши VPN/VLESS-серверы в удобный управляемый прокси-шлюз.

С его помощью можно раздать один внешний прокси для браузеров, телефонов, приставок, роутеров и Telegram MTProto, а также гибко выбрать, что должно идти через VPN, а что — напрямую.

---

## Что это такое и зачем нужно

**Proxy от Бориса** — это add-on для Home Assistant на базе **sing-box**, который помогает решить типичную задачу:

- у вас есть подписка на VPN/VLESS-серверы;
- вы хотите использовать её не только в одном приложении, а как **единый прокси-шлюз**;
- вам нужен **HTTP**, **SOCKS5**, **Telegram MTProto** и удобная **веб-панель управления**;
- вы хотите видеть клиентов, трафик, блокировки, логи и состояние маршрутизации;
- вам нужен режим, где **через VPN идут только заблокированные ресурсы**, а остальное открывается напрямую.

Именно для этого и сделан add-on.

---

## Основные возможности

### Прокси и доступ
- HTTP proxy
- SOCKS5 proxy
- Telegram MTProto proxy
- единый внешний порт MTProto для нескольких пользователей
- изменение рабочих портов прямо из интерфейса

### Работа с VPN-серверами
- импорт серверов через JSON
- импорт из текста `vless://`
- загрузка по ссылке подписки
- обновление подписки в один клик
- проверка пинга
- ручной выбор сервера
- режим `auto` с автоматическим выбором лучшего сервера
- приоритеты серверов, чтобы резервные узлы не мешали основным

### Маршрутизация
- весь трафик через VPN
- только заблокированные ресурсы через VPN
- только ручные правила через VPN
- всё напрямую, кроме Telegram MTProto
- ручные домены/IP, которые всегда идут через VPN
- ручные исключения, которые всегда идут напрямую
- обновляемые rule-set списки
- пресеты популярных сервисов

### Пользователи и клиенты
- отдельные пользователи с логином/паролем

- список клиентов онлайн и оффлайн
- доверенные клиенты

- ручные блокировки и разблокировки

### Безопасность
- авторизация на SOCKS5
- опциональная авторизация на HTTP
- геофильтр по RU CIDR + локальные сети + белый список
- автоблокировка подозрительных IP
- ручный белый и чёрный список CIDR

### Мониторинг и диагностика

- статистика трафика
- список соединений
- логирование по категориям
- кнопка «Обновить всё»

## Как это работает

Схема работы простая:

```
Клиент → Proxy от Бориса → выбранный VPN/VLESS-сервер → интернет
```

При этом add-on умеет работать в двух основных сценариях:

### 1. Обычный режим
Весь трафик клиента идёт через выбранный VPN-сервер.

### 2. Split-routing
Через VPN идут только нужные домены/IP (например заблокированные ресурсы), а весь остальной трафик идёт напрямую.

Это особенно полезно, если нужно:
- обойти блокировки;
- не гонять весь трафик через VPN;
- уменьшить задержки;
- использовать прокси на роутере только для определённых сервисов.

## Что нужно для работы

Минимально необходимо:

1. Home Assistant с поддержкой add-ons.
2. Установленный add-on **Proxy от Бориса**.
3. Ваши рабочие VPN/VLESS-серверы.
4. При необходимости — проброс внешних портов на роутере.

## Установка

### 1. Добавьте репозиторий
В магазине add-ons Home Assistant добавьте репозиторий, где опубликован этот проект.

### 2. Установите add-on
Установите **Proxy от Бориса** и дождитесь завершения сборки.

### 3. Первый запуск
После установки откройте конфигурацию add-on и задайте базовые параметры:

- `secret` — внутренний секрет приложения;
- `http_proxy_port` — стартовый HTTP-порт;
- `socks_proxy_port` — стартовый SOCKS5-порт;
- `telegram_proxy_enabled` — нужен ли Telegram MTProto;
- `telegram_proxy_port` — стартовый MTProto-порт;
- `proxy_username` и `proxy_password` — базовые учётные данные;
- `servers_json` — можно оставить пустым, если будете загружать серверы из интерфейса.

После этого запустите add-on и откройте веб-интерфейс.

> Важно: стартовые порты в конфигурации нужны для первого запуска. Дальше рабочие порты можно менять уже в самом интерфейсе add-on.

---

## Быстрый старт после установки

Рекомендуемая последовательность:

### Шаг 1. Добавьте VPN-серверы
Откройте вкладку **VPN-серверы** и загрузите серверы одним из способов:
- вставьте JSON;
- вставьте `vless://` ссылки;
- укажите ссылку подписки.

### Шаг 2. Проверьте пинг
Нажмите проверку пинга, чтобы понять, какие серверы реально доступны и какие быстрее.

### Шаг 3. Выберите режим работы
Во вкладке **Маршрутизация** выберите один из режимов:
- весь трафик через VPN;
- заблокированные списки + ручной ввод через VPN;
- только ручной список через VPN;
- всё напрямую, кроме Telegram.

### Шаг 4. Настройте пользователей
Во вкладке **Пользователи** создайте отдельных пользователей для людей или устройств.

### Шаг 5. Настройте порты и проброс
Во вкладке **Порты и доступ** задайте рабочие порты и затем настройте проброс портов на роутере.

### Шаг 6. При необходимости включите безопасность
Во вкладке **Безопасность** можно включить RU-фильтр, белые списки и автоблокировку.

## Как добавлять VPN-серверы

Поддерживаются три основных способа:

### Вариант 1. JSON
Подходит, если у вас уже есть готовый JSON-файл со списком серверов sing-box.

### Вариант 2. Текстовый список `vless://`
Можно вставить несколько ссылок подряд — add-on сам их разберёт.

### Вариант 3. Ссылка подписки
Самый удобный режим. Один раз вставляете ссылку подписки, после чего можно просто нажимать **обновить** и получать актуальный список серверов.

---

## Как работает режим “только заблокированные через VPN”

Во вкладке **Маршрутизация** есть режим, где:

- обновляемые списки заблокированных ресурсов идут через VPN;
- вручную добавленные домены/IP тоже идут через VPN;
- всё остальное идёт напрямую.

Это удобно, если вы хотите:
- открывать ChatGPT, GitHub, Discord, Nintendo и другие ограниченные ресурсы через VPN;
- при этом обычные сайты и сервисы оставлять на прямом доступе.

Если встретился сайт, которого нет в списках, просто добавьте его вручную в правила.

---

## Пользователи и Telegram MTProto

Add-on умеет создавать отдельных пользователей. Для каждого пользователя можно получить:

- логин и пароль для HTTP/SOCKS5;
- индивидуальный Telegram secret;
- готовую ссылку для Telegram.

При этом внешний MTProto-порт остаётся **общим**, так что не нужно пробрасывать новый порт на роутере для каждого человека.

---

## Безопасность: что важно понимать

Если у вас открыт доступ к прокси из интернета, рекомендуем сразу использовать:

1. **Авторизацию** на SOCKS5.
2. **HTTP auth**, если ваши клиенты её поддерживают.
3. **RU CIDR фильтр**, если прокси нужен только из России.
4. **Белый список IP/CIDR** для своих внешних адресов или роутеров.
5. **Автоблокировку** для мусорных сканирований.

> Если у вас есть устройства или роутеры за NAT, сначала внесите их в доверенные или белые списки, и только потом усиливайте ограничения.

## Кнопка “Обновить всё”

В шапке интерфейса есть кнопка **Обновить всё**. Она нужна для одного общего обслуживания системы:

- обновляет серверы из подписки;
- проверяет пинг серверов;
- обновляет rule-set списки маршрутизации;
- обновляет RU IP-список;
- в режиме `auto` подтверждает выбор лучшего сервера.

Это удобный способ быстро синхронизировать всё в один клик.

Основные рабочие данные находятся в каталоге `/data` add-on.

Например:
- настройки и служебные JSON-файлы;
- runtime-порты;

- правила маршрутизации;

## Типовые сценарии использования

### 1. Прокси для браузера и телефона
Используйте HTTP или SOCKS5 и авторизацию по логину/паролю.

### 2. Прокси для роутера
Роутер можно подключить к add-on как к внешнему прокси и далее маршрутизировать только нужные домены через него.

### 3. Telegram на MTProto
Включите Telegram-поддержку, задайте публичный адрес и используйте выданную ссылку.

### 4. Домашний split-routing
Отправляйте через VPN только заблокированные ресурсы, а весь обычный трафик оставляйте прямым.

## Советы по настройке

- Для повседневной работы удобно держать режим `blocked_plus_manual`.
- Российские серверы лучше использовать как резерв, а не как основные для обхода блокировок.
- Для каждого человека лучше создавать отдельного пользователя.
- После смены портов не забудьте обновить проброс портов на роутере.
- Если интерфейс показывает, что VPN не подтверждён, сначала проверьте импорт серверов и пинг.

---

## Если что-то не работает

Проверьте по порядку:

1. Add-on действительно запущен.
2. Серверы импортированы корректно.
3. Пинг серверов проходит.
4. Выбран правильный режим маршрутизации.
5. На роутере настроен проброс нужных портов.
6. Безопасность не заблокировала ваш IP.
7. Во вкладке **Диагностика** нет ошибок запуска `sing-box` или Telegram proxy.
