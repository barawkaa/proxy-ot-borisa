# Согласованные функции

| Функция | Раздел 5.1 |
|---|---|
| Ручной/автоматический выбор | Главная |
| Подписки/ручные серверы/общий список | Серверы |
| Проверка задержки и доступности | Серверы, Диагностика |
| Отказ → проверка резервов → замена | Планировщик |
| MTProxy, ссылка/QR/полный секрет | Telegram MTProxy |
| Единая карточка клиента | Telegram MTProxy, Настройка прокси |
| HTTP/SOCKS5 и порты | Настройка прокси |
| Активные клиенты и история | Клиенты и история |
| Только выбранные сайты через VPN | Настройки → Маршрутизация |
| Прямые исключения/доменные/IP списки | Настройки → Маршрутизация |
| Режим клиента | Карточка клиента |
| Trusted CIDR, блокировки, allowlist, автобан | Настройки → Доступ |
| Фильтр страны | Настройки → Доступ, обновление списков |
| Срок действия и месячный лимит | Карточка клиента |
| Трафик подписки | Вкладка подписки |
| Резервная копия/импорт | Настройки |
| Хранение/очистка | Настройки |

Редкие параметры доступа и внешних списков пока доступны через JSON-редактор внутри настроек. Главные действия имеют обычные формы. Исходные дополнительные данные 4.x сохранены для сверки; наличие их в архиве не означает, что каждое старое поле применяется автоматически.
