# Proxy от Бориса 5.3

Полная версия приложения для Home Assistant OS / aarch64.

- Единая строка действия: выполнение, прогресс, результат или ошибка на той же странице. Операции сохраняются в ограниченном журнале.
- HTTP 401/403/429 и проверка браузера отделены от отсутствия соединения. Подробности показывают код и подтверждённую причину, без догадок о блокировке VPN.
- Telegram: обмен MTProto с проверкой nonce; проверка секретного Fake TLS соединения через собственный MTProxy; каналы DC 2/4/5; опциональная загрузка ограниченного фрагмента контрольного файла через MTProto. Качество Telegram и медиа учитывается в выборе; зависшие соединения отказавшего маршрута закрываются при восстановлении.
- Главная считает клиентов отдельно от соединений. Telegram-соединения привязаны к проверенному секрету и исходному IP; внутренние проверки исключены из пользовательской статистики.
- Общая защита входов HTTP, SOCKS5, HTTP по IP и MTProxy: лимиты соединений, ограничение попыток входа, временная блокировка, просмотр и снятие блокировок.
- Отдельный HTTP-порт без пароля: домашние подсети, внешние разрешённые адреса, очередь одобрения, запрет и пауза, срок доступа, маршрут, история. До одобрения возвращается 403 без исходящего запроса. Отзыв доступа закрывает соединения.
- Приглашения ограничены сроком и привязаны к IP. По умолчанию Telegram уведомляет только после приглашения и настоящего прокси-запроса. Неизвестные адреса остаются в тихой очереди; сообщения объединяются и ограничены частотой.
- Бот Home Assistant может отправлять уведомления без вмешательства в его webhook/получение обновлений. Кнопки разрешения в Telegram — только для отдельно настроенного бота и указанного владельца.

## Обновление и настройка

Старые подписки, клиенты, секреты, маршруты и история сохраняются. Новый HTTP-порт, уведомления и загрузка контрольного файла выключены до настройки владельцем. Включение этих функций не требуется для работы прежних прокси.

Для HTTP по IP укажите фактические домашние подсети. Приложение не открывает произвольные частные сети автоматически и не меняет проброс портов роутера. При NAT/CGNAT одобряется весь видимый внешний IP; достоверного количества устройств за ним нет. HTTP по IP не допускает обращения к частным адресам назначения.

Контроль медиа требует Telegram API ID/hash и токен бота. В интерфейсе можно один раз создать контрольный файл в указанном чате; последующие проверки не отправляют сообщения. Успех одной загрузки подтверждает этот файл и DC, а не все видео Telegram. Без настройки статус медиа остаётся «не проверено».

## Проверки и откат

Результат точного коммита — в GitHub Actions: модульные/API проверки, настоящие sing-box и MTG, защищённый Fake TLS вход, контрольный MTProto обмен, браузер на компьютере и телефоне, кеш старых версий, запуск и интерфейс ARM64 образа. Подробные границы: `docs/VALIDATION.md`.

Предыдущие теги и релизы не меняются. Для отката доступны полные исходники прежних релизов. GitHub хранит код, а личные данные и настройки — резервная копия Home Assistant. Возврат на 5.2 отключает новые функции 5.3; он не превращает их в функции старой версии. Реальная домашняя сеть, конкретные подписки и контрольный бот владельца не воспроизводятся в CI.
