# Proxy от Бориса 5.4

Полная версия с независимой работой четырёх прокси и подключением к Home Assistant.

- Раздельные серверы, резерв, ручной/автоматический выбор и требования проверки HTTP, SOCKS5, Telegram и HTTP по IP.
- Главная: состояние каждого прокси, задержка, причина выбора, время смены, резерв; мастер подключения устройств.
- Общая форма показывает все четыре порта, включая 2084; отдельные вкладки настройки.
- Уведомления через существующих ботов HA: выбор нескольких получателей и дополнительные ID чатов; отдельный ручной режим с токеном сохранён.
- Локальная интеграция Lovelace: датчики, переключатели, выбор сервера, кнопка проверки; стандартная компактная карточка без HACS/MQTT.
- Общие измерения, приоритет активных маршрутов, проверка резервов, паузы для отказавших узлов, объяснение ограничений проверки сайтов.
- Срок внешнего IP-разрешения по умолчанию — 7 дней. Старые разрешения сохраняются; бессрочные доступны явно.
- README переписан для нового пользователя. Личные данные остаются в резервных копиях HA, код — в GitHub.

## Обновление и совместимость

Данные 5.x, подписки, доступы и секреты сохраняются. Предыдущий ручной выбор переносится в четыре профиля. Для нового приложения основной способ уведомлений — HA; ранее введённый токен сохраняет прямой режим.

Уведомления HA не требуют установки дополнительной интеграции Proxy. Для сущностей Lovelace: Настройки → Подключение и карточка HA → Установить интеграцию. Затем нужен перезапуск **Home Assistant Core в удобное время**, добавление интеграции «Proxy от Бориса» и карточки. Само приложение Core не перезапускает. Установщик изменяет только собственный каталог custom_components/boris_proxy и файл локального подключения; чужой каталог без отметки управления не перезаписывается.

## Откат

Сохраните штатную резервную копию приложения HA перед обновлением. Старый релиз v5.3 остаётся в истории. Для восстановления точного состояния используйте резервную копию HA; исходный архив v5.3 сохраняет код, но не ваши данные. При откате на 5.3 отключите сопровождающую интеграцию Proxy в HA: API сущностей появился в 5.4.

## Проверки и ограничения

Релиз создаётся только после успешных обязательных jobs точного коммита main. Ссылка на запуск добавляется автоматически ниже. Тесты проверяют контролируемые сценарии, а не доступность всех VPN-провайдеров. Один Telegram-файл не подтверждает все видео; фактическая доставка вашим ботом и длительная работа Raspberry Pi требуют проверки в домашней сети.
