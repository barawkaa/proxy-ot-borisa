# Proxy от Бориса 5.3

Все настройки доступны через «Открыть веб-интерфейс» Home Assistant.

1. Перед переходом с 4.x сделайте резервную копию дополнения вместе с данными.
2. В «Серверы» добавьте подписку, откройте её вкладку и нажмите «Обновить подписку».
3. На главной оставьте автоматический выбор или выберите сервер вручную.
4. В «Настройка прокси» укажите адрес подключения; в карточке клиента скопируйте пароль или ссылку MTProxy.

Если что-то не работает, начните с «Диагностика → Проверить всё». Не нужно собирать десятки журналов.

Ссылки подписок, пароли, секреты и полная резервная копия — приватные данные. Диагностический отчёт содержит только состояние и события без ключей.

Статус TCP Telegram не подтверждает отправку сообщений. Российские блокировки и конкретную подписку проверяют с вашего Home Assistant. SOCKS5 поддерживает TCP CONNECT.

GitHub: https://github.com/barawkaa/proxy-ot-borisa


## Доступ по IP

В разделе «Доступ по IP» включите отдельный порт и перечислите домашние CIDR. Неизвестный внешний адрес получает 403 до разрешения владельца. Приглашение только выделяет ожидаемый запрос для уведомления, а не открывает доступ. При смене IP требуется новое разрешение. За одним внешним IP может быть несколько устройств.

## Уведомления и контроль медиа

Боту нужны токен, ID чата и ID владельца. Для существующего бота Home Assistant приём callback оставьте выключенным. Для отдельного бота доступны кнопки разрешения/запрета; чужой пользователь или старое уведомление не меняют доступ.

В Telegram → «Настроить проверку медиа» однократно задаются API ID/hash и токен. Кнопка создания контрольного файла сохраняет file_id автоматически после отправки в выбранный чат. Повторные проверки скачивают фрагмент без сообщений. Скорость короткого фрагмента не гарантирует скорость всех видео.

## Версия 5.4: отдельные прокси

«Настройка прокси» содержит четыре вкладки. У каждого прокси свои сервер, резерв, ручной выбор и требования доступности. Общая форма «Адреса и все порты» показывает также HTTP по IP (2084). Маршрут клиента имеет приоритет над маршрутом прокси; затем применяются общие правила.

«Подключить устройство» на главной предлагает Telegram, домашнюю технику, приглашение знакомому и приложение с логином/паролем. Секреты клиентов и история остаются в прежних разделах.

### Уведомления через уже настроенный Telegram HA

Настройки → Уведомления Telegram → Через Home Assistant. Выберите получателей и включите уведомления. Дополнительные ID чатов вводятся в раскрывающемся блоке для выбранного бота HA. Эти ID должны быть разрешены в его интеграции. Сохраните, затем выполните тест. Приложение вызывает действия HA и не читает токены ботов. Если интеграция HA не работает (например, ошибка прокси 407), сначала исправьте её соединение.

Вкладка «Бот вручную» сохраняет независимый способ с токеном и ID. Для бота, который уже получает обновления в HA, приём кнопок здесь выключен.

### Lovelace

Настройки → Подключение и карточка HA → Установить / обновить интеграцию. Это явная установка companion из текущего релиза, без изменения configuration.yaml. После установки перезапустите Core в удобное время и добавьте интеграцию «Proxy от Бориса». Данные локальной связи подставляются автоматически.

В том же окне приведён YAML компактной штатной карточки. Нажатие на состояние прокси показывает резерв, последнюю смену, задержку и результаты. Переключатели включают прокси, кнопка выполняет проверку и автовыбор с сохранением ручного режима. Для ручного выбора добавьте нужную сущность select. При недоступном приложении HA показывает unavailable вместо прежнего рабочего статуса.

Доступ интеграции можно отключить в приложении. Передача идёт локально с отдельным ключом, в состояниях нет подписок, секретов и адресов клиентов. Частота обновления — 30 секунд. История сущностей подчиняется настройкам Recorder самого HA; приложение не меняет глобальные сроки Recorder.

### Хранение и откат

Персональные данные находятся в /data приложения и включаются в его штатную резервную копию HA (backup_exclude не задан). Companion и файл связи находятся в конфигурации HA и требуют включения Home Assistant в резервную копию. GitHub не хранит эти данные. Перед обновлением сохраняйте копию HA с приложением; прежние теги остаются неизменными.

В HA-режиме ручные ID также должны быть разрешены выбранному боту в интеграции Telegram. Текст уведомлений отправляется без разметки, чтобы имена клиентов и спецсимволы не ломали доставку. Частые значения пинга и время проверки доступны в сущностях, но исключены из Recorder; срок остальной истории HA задаётся самим Home Assistant.
