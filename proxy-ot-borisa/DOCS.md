# Proxy от Бориса 5.3

Все настройки доступны через «Открыть веб-интерфейс» Home Assistant.

1. Перед переходом с 4.x сделайте резервную копию дополнения вместе с данными.
2. В «Серверы» добавьте подписку, откройте её вкладку и нажмите «Обновить подписку».
3. На главной оставьте автоматический выбор или выберите сервер вручную.
4. В «Настройка прокси» укажите адрес подключения; в карточке клиента скопируйте пароль или ссылку MTProxy.

Если что-то не работает, начните с «Диагностика → Проверить всё». Не нужно собирать десятки журналов.

Ссылки подписок, пароли, секреты и полная резервная копия — приватные данные. Диагностический отчёт содержит только состояние и события без ключей.

Статус TCP Telegram не подтверждает отправку сообщений. Российские блокировки и конкретную подписку проверяют с вашего Home Assistant. SOCKS5 поддерживает TCP CONNECT.

GitHub: https://github.com/barawkaa/proxy-ot-borisa


## Доступ по IP

В разделе «Доступ по IP» включите отдельный порт и перечислите домашние CIDR. Неизвестный внешний адрес получает 403 до разрешения владельца. Приглашение только выделяет ожидаемый запрос для уведомления, а не открывает доступ. При смене IP требуется новое разрешение. За одним внешним IP может быть несколько устройств.

## Уведомления и контроль медиа

Боту нужны токен, ID чата и ID владельца. Для существующего бота Home Assistant приём callback оставьте выключенным. Для отдельного бота доступны кнопки разрешения/запрета; чужой пользователь или старое уведомление не меняют доступ.

В Telegram → «Настроить проверку медиа» однократно задаются API ID/hash и токен. Кнопка создания контрольного файла сохраняет file_id автоматически после отправки в выбранный чат. Повторные проверки скачивают фрагмент без сообщений. Скорость короткого фрагмента не гарантирует скорость всех видео.
