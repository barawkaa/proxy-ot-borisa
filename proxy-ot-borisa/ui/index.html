Зарегистрированные пользователи прокси

Создавай отдельного пользователя для каждого человека/устройства. SOCKS/HTTP получают свой логин и пароль. Telegram получает свой MTProto secret. Внешний порт общий для всех пользователей: 2083.

Добавить пользователя

После создания пользователю будут показаны логин, пароль, порт и Telegram-ссылка. Для Telegram используется один общий внешний порт из настроек add-on. У каждого пользователя разный secret, поэтому новые порты на роутере пробрасывать не нужно.

Для неизвестных внешних IP автобан полезен. Для роутеров/шлюзов лимиты могут быть очень большими, поэтому доверенные и зарегистрированные клиенты должны быть исключены из автобана.
